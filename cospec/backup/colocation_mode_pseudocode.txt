PSEUDO CODE: _maybe_change_colocation_mode()

1. IF selective validator is NOT trained
   RETURN (stay in colocation mode)

2. IF elapsed time < minimum dwelling time
   RETURN (prevent rapid switching)

3. Calculate current batch size and update EMA
   current_batch_size = engine1_requests + engine2_requests
   batch_size_ema = update_ema(current_batch_size)

4. Get performance prediction ratio for current engine
   ratio = predict_colocation_speedup_ratio(batch_size_ema)

5. IF currently in colocation mode:
   IF ratio < (1 - performance_threshold):
       increment consecutive_non_colocation_count
       IF consecutive_non_colocation_count >= threshold:
           SWITCH to non-colocation mode
           select_engine_with_more_requests()
           set_speculative_tokens_to_ema_value()
           reset_counters()
   ELSE:
       reset consecutive_non_colocation_count

6. ELSE (currently in non-colocation mode):
   IF ratio > (1 + performance_threshold):
       increment consecutive_colocation_count
       IF consecutive_colocation_count >= threshold:
           SWITCH to colocation mode
           set_speculative_tokens_to_maximum(7)
           reset_counters()
   ELSE:
       reset consecutive_colocation_count

7. IF mode was switched:
   update_last_switch_time()
   log_mode_change()
